# Billeder til “Vi tilbyder”

Læg billederne til hover-effekten i denne mappe.

Navngiv dem efter kategorien, fx:
- børnefødselsdag.jpg
- sommerfest.jpg
- kulturevent.jpg
- festival.jpg
- mode-editorial.jpg
- kursus.jpg

Billedformatet kan være .jpg, .jpeg, .png eller .webp. Når billederne er lagt ind, kobles de til de respektive kategorier på hjemmesiden.
